# 📍 Transformer Address Parser — 项目简介

## 项目概述

**Transformer Address Parser** 是一个基于 Transformer 架构的中文地址解析系统，能够将非结构化的文本地址自动拆解为标准的五级行政区划（省、市、区/县、街道、详细地址）。项目采用 **Encoder-Decoder** 结构，利用预训练的 **BERT** 模型提取地址语义特征，并通过 **Cross-Attention** 机制逐级生成各级行政区划，上一级的输出作为下一级生成的上下文输入，实现层级化、渐进式的地址解析。

## 核心技术

- **编码器 (Encoder)**：使用预训练 BERT 模型对输入地址文本进行自注意力编码，捕获字词间的全局语义关系，输出丰富的上下文表示。
- **解码器 (Decoder)**：基于 Transformer Decoder 结构，每一级行政区划的生成均通过 Cross-Attention 与 BERT 编码结果交互，同时将上一级生成的 token（如省级名称）作为当前级的额外输入，形成“级联”生成链路。
- **逐级生成策略**：五级行政区（省 → 市 → 区/县 → 街道 → 详细地址）依次生成，每一级的预测结果被拼接到 decoder 的输入序列中，使模型能够利用已确定的上级信息缩小下级候选范围，提高准确率。

## 主要特性

- 🧠 **深度语义理解**：BERT 编码器能够处理地址中常见的简写、别名、模糊表述等问题。
- 🔗 **层级依赖建模**：通过逐级输入传递，模型自然学习到行政级别的嵌套关系（如“西安市”必然属于“陕西省”）。
- 🎯 **高精度解析**：在公开中文地址数据集上达到 SOTA 效果，尤其对长尾、不规则地址鲁棒性强。
- ⚙️ **轻量部署**：基于 PaddleNLP 框架，支持动态图推理，可导出为静态图模型用于生产环境。

## 技术栈

- **深度学习框架**：PaddlePaddle / PaddleNLP 3.0.0
- **预训练模型**：BERT-base-chinese（可替换为其他 BERT 变体）
- **SDK 与工具**：AI Studio SDK 0.2.0（数据管理与云端训练）
- **项目管理**：Python 3.10+，Conda 环境隔离，pyproject.toml 依赖管理

## 应用场景

- 电商物流地址标准化
- 政务数据治理与地理编码
- 地图服务 POI 地址补全
- 金融风控中的地址真实性校验
